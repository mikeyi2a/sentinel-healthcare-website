## 1. Project Overview & Layout Standards

Sentinel Healthcare Consulting Limited is a Nigerian healthcare risk-management consultancy based in Lekki, Lagos. They help hospitals, HMOs/insurers, and government/development partners manage clinical risk, patient safety, and regulatory compliance.

Tagline: **"Safer care, by design."**

### Layout Guardrails (Strict Pixel Standards)
- **Desktop Standard Container Max-Width**: `1440px` (`max-w-[1440px]`)
- **Horizontal Container Padding**: `24px` mobile (`px-6`), `48px` desktop (`lg:px-12`)
- **Container Structure**: `mx-auto w-full max-w-[1440px] px-6 lg:px-12`
- **Section Corner Radius (Hero / Major Cards)**: `20px` mobile (`rounded-[20px]`), `40px` desktop (`lg:rounded-[40px]`)
- **UI Element Corner Radius**: `6px` (`rounded-[6px]`)
- **Buttons**: Flat styling, capital case (`uppercase tracking-[0.11em] text-xs font-semibold`), with text-roll slide-up hover animation.
